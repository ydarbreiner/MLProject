Point Cloud Viewer Help

Navigation Controls

  • Rotate: Left click + drag
  • Pan: Right click + drag or Middle click + drag
  • Zoom: Mouse wheel or Ctrl + drag

Keyboard Shortcuts

  • R: Reset view
  • F: Fit to view
  • 1-5: Switch color modes
  • +/-: Adjust point size

Performance Tips

  • Adjust point budget for better performance
  • Enable frustum culling for large datasets
  • Use Eye Dome Lighting for better depth perception
